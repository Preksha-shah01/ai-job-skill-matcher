# AI-Powered Job & Skill-Matching Platform

A full-stack application for connecting users with relevant job opportunities based on their skills, professional profile, resume, and career preferences.

## Project Goal

The project will progressively explore full-stack development, REST APIs, databases, authentication, NLP, machine learning, recommendation systems, testing, security, and deployment.

## Planned MVP

- User registration and authentication
- Professional user profile
- Skills management
- Job listings
- Job search and job details
- Basic skill-based job matching
- Saved jobs
- Job applications

## Planned Technology Stack

### Frontend
